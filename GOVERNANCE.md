# Project Governance

GlycemicGPT's governance is maintained once, org-wide, in the organization `.github` repository so it can't drift between repos.

**Canonical document → [GOVERNANCE.md in the org `.github` repo](https://github.com/lumose-health/.github/blob/main/GOVERNANCE.md)**

It covers project roles and permissions, how contributors advance, decision-making and disputes, the funding and compensation model, branch protection, code ownership, automation, and security governance -- for every repository in the organization.
