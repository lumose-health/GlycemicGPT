# Wear OS Architecture

The Android phone app, the Wear OS watch-side services (`:wear-device`), and the WFF watch faces (`:watchface`) now live in [`lumose-health/android-unofficial`](https://github.com/lumose-health/android-unofficial). That repository's [`docs/dev/wear-os-architecture.md`](https://github.com/lumose-health/android-unofficial/blob/main/docs/dev/wear-os-architecture.md) is the source of truth for the phone-watch data layer architecture.
