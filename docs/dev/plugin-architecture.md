# Plugin Architecture

The mobile app, and the device-data plugin SDK it hosts (`:pump-driver-api`, shipped plugins like Tandem), now live in [`lumose-health/android-unofficial`](https://github.com/lumose-health/android-unofficial). That repository's [`docs/dev/plugin-architecture.md`](https://github.com/lumose-health/android-unofficial/blob/main/docs/dev/plugin-architecture.md) is the source of truth for the plugin architecture as implemented.

See [CONTRIBUTING.md](../../CONTRIBUTING.md#device-data-drivers) in this repo for the contribution model that still applies platform-wide.
