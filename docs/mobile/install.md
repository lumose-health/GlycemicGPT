---
title: Install the Android App
description: Where to find the Android companion app and its install guide.
---

The Android app is **required** to connect your insulin pump over Bluetooth -- the platform in this repository cannot read pump data on its own. See [Get Started](../get-started.md) for setting up the platform first.

The Android phone app, Wear OS watch face, and pump-driver plugins have moved to their own repository: [`lumose-health/android-unofficial`](https://github.com/lumose-health/android-unofficial).

**Step-by-step install guide:** [`docs/mobile/install.md`](https://github.com/lumose-health/android-unofficial/blob/main/docs/mobile/install.md) in that repository -- includes the app's home-screen status icons (see [The App Status Icons](./status-icons.md) for what each one means).

**Downloads:** [Releases](https://github.com/lumose-health/android-unofficial/releases) -- the latest entry without a "Pre-release" label is the stable build; [`dev-latest`](https://github.com/lumose-health/android-unofficial/releases/tag/dev-latest) always carries the newest development build.
