---
title: Install the Wear OS Watch Face
description: Optional at-a-glance glucose monitoring on a Wear OS watch.
---

**It's optional** -- the platform and phone app work without the watch face. See [Install the Android App](./install.md) first if you haven't already.

The Wear OS watch face has moved to its own repository, alongside the Android phone app: [`lumose-health/android-unofficial`](https://github.com/lumose-health/android-unofficial).

**Step-by-step install guide:** [`docs/mobile/wear-os.md`](https://github.com/lumose-health/android-unofficial/blob/main/docs/mobile/wear-os.md) in that repository.

**Downloads:** [Releases](https://github.com/lumose-health/android-unofficial/releases) -- the latest entry without a "Pre-release" label is the stable build; [`dev-latest`](https://github.com/lumose-health/android-unofficial/releases/tag/dev-latest) always carries the newest development build.
